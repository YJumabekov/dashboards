## Обязательные предупреждения

> ⚠️ **SME верификация обязательна.** Каждый сгенерированный текст, тест, сценарий — проверяется инженером по ОТ до публикации. Claude — ускоритель, не замена эксперту.

> ⚠️ **Защита данных.** Не загружать: схемы объектов, персональные данные, конфиденциальные регламенты с грифом. Только обезличенные материалы.

> ⚠️ **Визуальная точность.** AI-изображения с СИЗ — проверять вручную: каска надета, карабины корректны, нет опасных действий без защиты. ИИ часто ошибается в деталях.

## Экономный режим — /эконом

Активируется фразой `/эконом` или «работаем в экономном режиме».

### Что меняется в экономном режиме

| Обычный режим | Экономный режим |
|---|---|
| Claude объясняет что делает | Только вывод, без объяснений |
| Skill 08 после каждого шага | Skill 08 только после финальной версии подтемы |
| Brand Kit сравнение при каждом запуске | Только первый раз в проекте |
| Полный план слайдов с вопросом | Краткий список: «№1 [название] / №2 [название] — ок?» |
| DOCX запрашивается явно | То же — без изменений |

### Что НЕ меняется в экономном режиме

- Одна подтема за раз — обязательно
- Humanization pass + anti-AI check — обязательно  
- SME верификация и защита данных — обязательно
- НПА точность — обязательно

### Как максимально экономить токены

**Правило 1 — Загружай скиллы по очереди, не все сразу:**
```
/kaz-safe-hse          ← всегда
/anthropic-skills:sental-identity  ← только когда нужен визуал
/anthropic-skills:video-avatar-script  ← только когда пишешь сценарий
```

**Правило 2 — Одна задача на сессию:**
- Сессия 1: только Skill 02 (сценарий подтемы 1.1)
- Сессия 2: только Skill 03 (слайды для 1.1)
- Смешивать в одной сессии = двойной расход

**Правило 3 — Используй краткие триггеры:**
```
«подтема 1.2, тип Б, аудитория рабочие, ОПО нефть»  ✅
«пожалуйста напиши мне сценарий для подтемы...»      ❌ (лишние токены на вежливость)
```

**Правило 4 — Дай всё сразу, не дроби:**
Лучше один большой контекст в начале, чем 5 уточняющих вопросов по ходу.
