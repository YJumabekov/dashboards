# KazSafe HSE — Извлечённые уроки

Лог уроков по ходу создания реальных курсов.
Формат: `[Дата] | [Скилл] | Урок | Что изменено`

---

## Как добавлять уроки

В любой момент скажи Клоду:
```
/урок [что узнали]
```
Claude сам решит: обновить файл скилла или только залогировать здесь.
